One notebook.
Context across your AIs.

Keep useful preferences, project decisions, and conversation handoffs in Markdown files in your own OneDrive.

How it works

  1. Install the Shared Notebook plugin in a supported AI host.
  2. Connect its remote MCP connector and sign in to your Microsoft account.
  3. Read relevant notes and save useful memories with the host’s approval controls.

The hosted service needs no local server. Each AI connection uses the OneDrive account authorized during sign-in. Website account switching does not change an AI connection.

Current release: 0.2.0

Available as a personal-install Claude package. Public directory submissions are being prepared; this is not an approved directory listing.

The service is free. Your AI and Microsoft providers may have separate account or subscription requirements.

Open the memory editor — the editor may require AXHub access in addition to OneDrive sign-in.

You control what is remembered

The service processes only content sent through its tools. It cannot silently import all your chats or guarantee automatic memory in every conversation. Avoid passwords and sensitive personal details. Files live in OneDrive; requests pass through Cloudflare, AXHub, Microsoft and your connected AI provider.
